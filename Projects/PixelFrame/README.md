# Pixel Frame
Native macOS (SwiftUI + AppKit + ImageIO) Divoom-style pixel display. Apple silicon, macOS 14+.

## Build
    ./build_app.sh && open build/PixelFrame.app
or `open Package.swift` in Xcode and press Run.
(Needs Xcode or `xcode-select --install`.)

## Use
Add Images/Folders... -> pick resolution -> Show Full Screen.
Esc exit · Space play/pause · Left/Right prev/next · double-click toggles full screen.
